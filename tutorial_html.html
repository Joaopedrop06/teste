1. Estrutura e conceitos fundamentais

HTML (HyperText Markup Language) estrutura o conteúdo de uma página. Ele usa elementos formados por uma tag de abertura, conteúdo e tag de fechamento. Algumas tags são vazias, como <img>.

<!DOCTYPE html>
<html lang="pt-BR">
	<head> <title>Minha página</title> </head>
	<body>
		<h1>Olá, mundo!</h1>
	</body>
</html>
Semântica: use tags pelo significado, como <header>, <main> e <footer>.
Atributos: fornecem informações extras, por exemplo href, src, alt e class.
Acessibilidade: escreva textos alternativos, mantenha títulos em ordem e use labels em formulários.

2. Principais tags HTML

Texto e organização

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<p>Um parágrafo com <strong>destaque</strong> e <em>ênfase</em>.</p>
<hr>
<div>Bloco genérico</div>
<span>Trecho em linha</span>

Links, imagens e listas

<a href="https://developer.mozilla.org/pt-BR/" target="_blank">Documentação</a>
<img src="foto.jpg" alt="Descrição da foto" width="300">
<ul><li>Item sem ordem</li></ul>
<ol><li>Primeiro passo</li></ol>

Tabelas e formulários

<table>
	<tr><th>Produto</th><th>Preço</th></tr>
	<tr><td>Livro</td><td>R$ 30</td></tr>
</table>
<form>
	<label for="email">E-mail:</label>
	<input id="email" type="email" required>
	<button type="submit">Enviar</button>
</form>

Mídia e conteúdo incorporado

<audio controls src="musica.mp3"></audio>
<video controls width="400" src="video.mp4"></video>
<iframe src="https://example.com" title="Exemplo"></iframe>

3. Práticas recomendadas

  • Use um único <h1> por página e mantenha a hierarquia de títulos.
  • Prefira HTML semântico e CSS para aparência.
  • Valide o documento, teste no celular e confira o teclado.
  • Indente o código e use nomes claros para classes.
Desafio: crie uma página de apresentação com um cabeçalho, uma lista de habilidades, uma imagem com alt, um formulário de contato e um rodapé. Depois, valide o HTML e abra o arquivo no navegador.

4. Resumo sobre Git

Git é um sistema de controle de versão: registra alterações, permite voltar a versões anteriores e facilita o trabalho em equipe. GitHub é uma plataforma para hospedar e colaborar em repositórios.

git init                         # inicia um repositório
git status                       # verifica alterações
git add tutorial_html.html       # prepara o arquivo
git commit -m "Cria tutorial HTML" # salva uma versão
git log --oneline                # consulta o histórico
git branch nova-funcionalidade   # cria uma branch
git switch nova-funcionalidade   # muda de branch
git push origin main             # envia ao remoto
git pull origin main             # atualiza o projeto

Fluxo comum: editar → git status → git add → git commit → git push. Faça commits pequenos e descreva claramente cada mudança.

5. Resumão final

Conceitos e tags HTML

HTML estrutura conteúdo com elementos e atributos. Use semântica, acessibilidade, títulos, links, imagens, listas, tabelas e formulários corretamente.

Git

Controle versões com repositórios, commits e branches. O fluxo essencial é adicionar, registrar, revisar e sincronizar alterações.

Tudo junto
