Git: comandos principais e uso prático

O Git é um sistema de controle de versão usado para registrar alterações em arquivos e colaborar em projetos. Abaixo estão os comandos mais importantes, com explicações e exemplos simples para usar no dia a dia.

1. git init

Inicializa um repositório Git em uma pasta local.

git init

Exemplo:

mkdir meu-projeto
cd meu-projeto
git init

Esse comando cria a pasta .git, que guarda o histórico do projeto.

2. git clone

Baixa um repositório já existente para sua máquina.

git clone <url-do-repositorio>
git clone https://github.com/usuario/projeto.git

Isso cria uma cópia local do projeto e já conecta o repositório remoto ao local.

3. git status

Mostra o estado atual do repositório: arquivos alterados, novos e prontos para commit.

git status
git status

Use sempre antes de fazer um commit para verificar o que foi modificado.

4. git add

Adiciona arquivos à área de staging, preparando-os para commit.

git add <arquivo>
git add index.html
git add .

git add . adiciona todos os arquivos alterados da pasta atual.

5. git commit

Salva as alterações na história do projeto com uma mensagem.

git commit -m "mensagem do commit"
git commit -m "Adiciona página inicial do projeto"

O commit cria um ponto de salvamento no histórico do código.

6. git log

Mostra o histórico de commits do projeto.

git log
git log

Você consegue ver quem fez a alteração, quando e qual mensagem foi usada.

7. git branch

Lista ou gerencia ramificações do projeto.

git branch
git branch
git branch nome-da-branch

As branches permitem trabalhar em versões separadas do código sem afetar a principal.

8. git checkout / git switch

Muda de uma branch para outra.

git checkout nome-da-branch
git checkout feature-login
git switch main

git switch é a opção mais moderna e clara para trocar de branch.

9. git merge

Une uma branch em outra, combinando as alterações.

git merge nome-da-branch
git checkout main
git merge feature-login

Esse comando integra o trabalho feito em outra branch na branch atual.

10. git pull

Busca e incorpora as alterações mais recentes do repositório remoto.

git pull origin main
git pull origin main

Útil para manter seu projeto sincronizado com o repositório online.

11. git push

Envia seus commits para o repositório remoto.

git push origin main
git push origin main

Depois de concluir alterações locais, use esse comando para compartilhar com o time.

12. git remote -v

Mostra os repositórios remotos configurados no projeto.

git remote -v
git remote -v

Normalmente aparece a origem do GitHub, GitLab ou Bitbucket.

13. git diff

Mostra as diferenças entre versões do código.

git diff
git diff
git diff -- index.html

Ajuda a revisar exatamente o que foi alterado antes de fazer um commit.

14. git restore

Descarta alterações locais em arquivos para voltar ao último estado salvo.

git restore arquivo.txt
git restore index.html

Útil quando você quer reverter uma edição sem precisar apagar manualmente o arquivo.

15. git reset

Remove commits ou desfaz mudanças do staging/estado do projeto.

git reset --hard HEAD~1
git reset --soft HEAD~1
git reset --hard HEAD~1

Esse comando deve ser usado com cuidado, porque pode apagar alterações importantes.

Dica prática: um fluxo básico de trabalho no Git costuma ser:
  • git status para verificar o estado;
  • git add . para preparar arquivos;
  • git commit -m "..." para salvar alterações;
  • git pull antes de enviar alterações para evitar conflitos;
  • git push para subir o código.
Git é essencial para organizar projetos, colaborar em equipe e manter um histórico confiável do código.
